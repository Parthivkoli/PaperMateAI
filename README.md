# 📚 PaperMate AI - Your Research Companion

Welcome to **PaperMate AI**! 🚀 This web application is designed to help you **discover, read, and summarize** research papers effortlessly. Whether you're a student, researcher, or enthusiast, PaperMate AI ensures that you stay on top of the latest academic findings with AI-powered summarization.

---

## ✨ Features

✅ **Search for Research Papers**: Get relevant papers from arXiv with a single search.  
✅ **Read in an Organized Interface**: View abstracts and full PDFs in a clean, user-friendly UI.  
✅ **AI-Powered Summarization**: Generate summaries in three styles: **Brief**, **Abstract**, and **Detailed**.  
✅ **Customizable Summary Length**: Adjust summary length to suit your needs.  
✅ **Dark Mode Friendly**: Seamlessly adapts to light and dark themes for comfortable reading.  
✅ **Save and Export Summaries**: Save summaries locally or export them as text files for future reference.  
✅ **Multi-Language Support**: Summarize papers in multiple languages (coming soon).

## 🚀 Installation & Setup

### 1️⃣ Prerequisites
Ensure you have **Python 3.8+** installed. It’s recommended to set up a virtual environment to manage dependencies.

### 2️⃣ Clone the Repository
```sh
git clone https://github.com/Parthivkoli/PaperMateAI.git
cd PaperMateAI
```

### 3️⃣ Install Dependencies
```sh
pip install -r requirements.txt
```

### 4️⃣ Run the Application
```sh
streamlit run app.py
```

Once the app is running, open your browser and navigate to the provided local URL (usually `http://localhost:8501`).

## 📝 Usage Guide

1. **Enter a Search Term**: Type a keyword or phrase (e.g., "AI in Healthcare") in the search bar.  
2. **Browse Results**: View a list of relevant papers from arXiv. Click on a paper to see its abstract and PDF.  
3. **Choose Summarization Style**: Select from **Brief**, **Abstract**, or **Detailed** summarization in the sidebar.  
4. **Adjust Summary Length**: Use the slider to control the length of the summary.  
5. **Generate Summary**: Click the "Summarize" button to generate an AI-powered summary.  
6. **Save or Export**: Save the summary for later or export it as a text file.
